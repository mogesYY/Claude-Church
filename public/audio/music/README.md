# Background music

Drop MP3 files here to replace the generated instrumental:

| File | Where it plays |
|---|---|
| `menu.mp3` | Main menu |
| `solemn.mp3` | Opening shot and quiet scenes |
| `festive.mp3` | Leaving church after the Kidase, celebrations |

Until a file exists, the game generates a begena-and-krar style instrumental live (no voices).
